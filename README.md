# Smart Meal Planner & Nutrition Tracker

A modern, offline-first Flutter application for tracking meals, nutrition, and hydration with cloud synchronization.

## 🚀 Key Features
*   **Meal Planning**: Log Breakfast, Lunch, Dinner, and Snacks.
*   **Nutrition Tracking**: Track Calories, Protein, Carbs, and Fats.
*   **Goal Setting**: Set personal daily targets for calories and macronutrients.
*   **Analytics Dashboard**: Visualize weekly trends and goal achievement.
*   **Cloud Sync**: Real-time synchronization with Firebase Firestore.
*   **Offline First**: Works perfectly without internet using Hive local database.
*   **Hydration Tracker**: Animated water intake logger.

## 💧 Future Scope: Hydration Tracker
The current hydration tracker provides a simple and attractive way to log daily water intake. For future development, the following enhancements are planned:
*   **Smart Hydration Goals**: Automatically calculate water requirements based on user weight and activity.
*   **Smart Reminders**: Push notifications to drink water at regular intervals.
*   **Hydration Analytics**: Weekly and monthly trends for long-term consistency.
*   **Home Screen Widgets**: Quick-log widgets for instant tracking without opening the app.
*   **Temperature Integration**: Dynamically adjust goals based on local weather data.

## 🛠 Tech Stack
*   **Flutter**: Cross-platform UI.
*   **Riverpod**: State management.
*   **Hive**: Local NoSQL database.
*   **Firebase Firestore**: Cloud database and sync.
*   **FL Chart**: For data visualization.
